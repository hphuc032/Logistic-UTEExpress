24. JWT FILTER
==================================================

Implement OncePerRequestFilter.

Flow:

1. If SecurityContext already authenticated:
   do not replace it.

2. Find configured JWT auth cookie.

3. Missing cookie:
   continue chain.

4. Token exists:
   validate:
   - HS256 signature
   - issuer
   - audience
   - exp
   - iat validity / clock skew
   - subject
   - tokenVersion

5. Resolve account from DB.

6. Require ACTIVE.

7. Compare database tokenVersion.

8. Load current roles FROM DB.

9. Convert roles through RoleCode.

10. Build authenticated principal.

11. Put Authentication in SecurityContext.

12. Continue chain.

On:

expired token
bad signature
wrong issuer
wrong audience
malformed token
unknown user
inactive user
tokenVersion mismatch

DO NOT throw 500.

Clear authentication and continue anonymous.

Then:

protected route -> existing 401 handler
public route -> can still render anonymously.

Optionally expire invalid auth cookie safely.

Never log raw token.
