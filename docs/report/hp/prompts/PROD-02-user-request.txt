inspect and adapt.

==================================================
32. BEST-SELLING SQL
==================================================

Use aggregate/subquery/CTE.

Conceptually:

LEFT JOIN (
  SELECT oi.product_id,
         SUM(oi.quantity) AS sold_quantity
  FROM order_items oi
  JOIN orders o ON o.id = oi.order_id
  WHERE o.status = 'DELIVERED'
  GROUP BY oi.product_id
) sales ON sales.product_id = p.id

ORDER BY
COALESCE(sales.sold_quantity, 0) DESC

Tie-break:

p.created_at DESC
p.id DESC
