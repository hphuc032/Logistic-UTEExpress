4. WHY SHOP REGISTRATION MUST NOT USE /vendor/**
==================================================

A normal USER applying to become a Vendor does NOT yet have:

ROLE_VENDOR

Therefore:

DO NOT put shop application under:

/vendor/register
/vendor/shop/register

Those routes require VENDOR authority
and create a circular authorization problem.

Use an authenticated USER route.

Recommended:

GET  /user/shop/register
POST /user/shop/register

Recommended application/status page:

GET /user/shop

or:

GET /user/shop/application

Choose one consistent design after inspecting current UI conventions.

The route must remain under:

/user/**

so USER and existing VENDOR can reach it according to current SecurityConfig.
