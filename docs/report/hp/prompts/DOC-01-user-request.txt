## 3. Git workflow và bảo vệ source

Trước khi sửa file:

- Kiểm tra current branch, remote và working tree.
- Fetch trạng thái mới nhất của `develop`.
- Kiểm tra các PR liên quan và trạng thái merge hiện tại.
- Xác định source SHA được dùng để viết tài liệu.
- Không làm việc trực tiếp trên `main` hoặc `develop`.
- Không xóa hoặc ghi đè thay đổi local chưa commit.
